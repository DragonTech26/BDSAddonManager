BDS Addon Manager lets you manage addons for self-hosted Minecraft: Bedrock Edition servers through a clean, straightforward interface. It handles resource and behavior packs without the need to edit JSON files by hand.

## Features

- **Modern GUI**: Simple layout with familiar controls.
- **Pack Management**: Enable or disable packs, add or remove them, adjust load order, view dependencies, and handle subpacks.
- **Flexible Options**: Hide the server’s default packs and strip text modifiers if desired.
- **Self Contained**: Runs without installation.
- **Cross-Platform**: Works on Windows and Linux!

## Getting Started

1. Download the latest release for your operating system.
2. Make sure the server you want to edit is not running.
3. Enter the world folder path into BDS Addon Manager.
4. Navigate through the sidebar to manage content.
5. Save your changes and start the server.

## FAQ

**Q:** Does this support Minecraft: Java Edition?

**A:** No. This tool focuses on Bedrock Edition.

**Q:** Can I manage more than one server?

**A:** Yes. Recent worlds appear in a dropdown on the main menu. Only one world can be edited at a time.

**Q:** What pack formats are supported?

**A:** `.zip`, `.mcpack`, and `.mcaddon`.
